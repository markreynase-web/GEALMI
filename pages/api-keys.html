URL base

Autenticación

Manda tu API key en cada solicitud, en el encabezado Authorization:

Authorization: Bearer <tu_api_key>

Recursos

  • GET /ventas
  • GET /inventario
  • GET /clientes
  • GET /finanzas
  • GET /{recurso}/{id} — un registro puntual

Parámetros

  • desde, hasta — fechas AAAA-MM-DD
  • sucursal_id — en ventas, inventario y finanzas
  • pagina (desde 1) y limite (100 por defecto, máximo 500)

Respuesta

{ "datos": [ … ], "meta": { "total": 250, "pagina": 1, "limite": 100, "paginasTotales": 3 } }
